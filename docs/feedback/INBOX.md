# INBOX.md — 사용자 지시 / 피드백 (최우선)

이 파일은 사람이 직접 채워 넣는 지시함이다. 루프의 모든 이터레이션은
`docs/DESIGN.md`, `docs/STATUS.md`를 읽은 직후 **이 파일을 반드시 읽고,
여기 있는 항목을 다른 어떤 작업보다 먼저 처리한다.**

## 사용법 (사람용)

- 새 지시/피드백은 **맨 위에** 날짜와 함께 추가한다 (최신이 위).
- 처리가 끝난 항목은 에이전트가 `[처리됨]` 표시를 남기고 아래
  "처리된 항목" 섹션으로 옮긴다. 사람은 지우지 않아도 된다.
- 급한 지시는 `[긴급]` 태그를 붙인다.

## 처리 대기 중

- (2026-09-01) 네모 박스 대신 플레이어블(주인공) 캐릭터를 디자인한다. 캐릭터는
  흰 원피스를 입은 10살 전후의 한국인 여아로 설정한다. 캐릭터 디자인을 먼저
  컨펌받은 후, 도트 스프라이트를 제작하여 저장한다. (디자인은 거듭 고쳐질 수
  있으나, 본 목적은 반복된 플레이에서 이미지 변경이 없도록 확정하기 위함)
- (2026-09-01) 대화 시스템을 만든다. 쯔꾸르 게임과 유사한 방식으로, 대화 발생
  시 하단에 대화 영역을 만들어 텍스트를 출력한다. 대화의 시작은 해당 NPC를
  바라보고 스페이스바 키를 입력하는 것. 대화가 시작되면 스페이스바로 대화가
  진행되고, 더 이상 이어지는 대화가 없다면 종료된다.
- (2026-09-01) 대화 시스템을 테스트하기 위한 환경을 만든다. 임시로 툇마루에
  주인공 캐릭터와 동일한 외형이나 검은색으로 덮인 [그림자?] NPC를 만들고,
  대화하면 [...] 만 출력하도록 한다.
- (2026-09-01) 배경을 디자인한다. 현재 임시로 덮인 배경을 구체화한다. 쯔꾸르
  감성의 2D 디자인을 희망하며, 컨펌이 완료되면 쪼개진 어셋 형태로 저장한다.
