# ORDER-001 — 제미나이용 프롬프트 (복붙용)

[ORDER-001.md](ORDER-001.md)를 이미지 생성 AI에 바로 넣을 수 있게 정리한 버전.
**프롬프트 1개 = 이미지 1장.** 순서대로 따로 넣는다.

- **화풍 맞추기**: 가능하면 기존 시트 `assets/asset002.png`(또는 `asset004.png`)를 이미지로 같이 첨부하고 넣는다.
  첨부를 안 해도 프롬프트만으로 동작하게 써 두었다.
- **받은 결과물**: `assets/asset005.png`(프롬프트 1), `assets/asset006.png`(프롬프트 2)로 저장하고 알려주면
  잘라서 적용한다.
- 배경을 형광 분홍(#FF00FF) 단색으로 요청한다. 게임 그림에 안 쓰이는 색이라 지우기 가장 쉽다
  (체크무늬·격자 배경은 지울 때 그림이 같이 깎임 — v0.37 사례).

## 프롬프트 1 — 사방치기 + 열매 덤불 (OB-302, OB-103)

```
2D 탑다운 RPG용 픽셀아트 게임 에셋 시트를 그려줘. (첨부 이미지가 있다면 그 화풍과 색감, 픽셀 크기를 그대로 맞춰줘.)

[공통 조건]
- 1990년대 한국 시골 여름 마을이 배경인 게임. 부드럽고 따뜻한 16비트풍 픽셀아트, 약간 위에서 내려다본 시점(3/4 탑다운).
- 배경은 아무 무늬 없는 형광 분홍색(#FF00FF) 단색으로 꽉 채워줘. 체크무늬, 격자, 그라데이션, 테두리 금지.
- 오브젝트 2개를 좌우로 나란히, 서로 멀리 떨어뜨려 배치. 오브젝트 사이와 이미지 가장자리에 넉넉한 여백.
- 각 오브젝트는 전체가 완전히 보여야 함. 어느 부분도 이미지 밖으로 잘리면 안 됨.
- 글자, 번호, 라벨, 설명, 워터마크를 이미지 안에 절대 넣지 마.

[오브젝트 1 — 사방치기]
- 흙바닥 위에 흰 분필로 그린 한국식 사방치기 판. 위에서 내려다본 바닥 그림.
- 세로로 긴 형태(가로:세로 약 3:4). 아래에서 위로 네모 칸들이 1칸-2칸-1칸-2칸 식으로 이어지고, 맨 위는 반원 모양 칸.
- 맨 위 반원 칸까지 전부 이미지 안에 들어와야 함.
- 분필 선은 조금 지워지고 바랜 느낌. 흙바닥은 판 모양 주변으로만 약간 깔고, 그 바깥은 분홍 배경.
- 그림자 없음.

[오브젝트 2 — 열매 덤불]
- 붉은 열매가 여기저기 달린 둥글고 풍성한 초록 덤불. 정면에서 살짝 위로 본 시점.
- 세로가 조금 더 긴 형태(가로:세로 약 4:5). 덤불 아래 땅에 작은 타원형 그림자.
- 덤불 좌우 끝까지 전부 이미지 안에 들어와야 함. 잎 끝이 잘리지 않게.
```

## 프롬프트 2 — 챕터 2/3 키 아이템 6종 (OB-306~308, OB-310~312)

```
2D 탑다운 RPG용 픽셀아트 아이템 시트를 그려줘. (첨부 이미지가 있다면 그 화풍과 색감, 픽셀 크기를 그대로 맞춰줘.)

[공통 조건]
- 1990년대 한국 시골이 배경인 미스터리/호러 분위기 게임. 꿈속에서 줍는 물건들이라 전체적으로 살짝 탁하고 빛바랜 색감.
- 16비트풍 픽셀아트, 약간 위에서 내려다본 시점(3/4 탑다운). 바닥에 떨어져 있는 모습.
- 배경은 아무 무늬 없는 형광 분홍색(#FF00FF) 단색으로 꽉 채워줘. 체크무늬, 격자, 그라데이션, 테두리, 칸 구분선 금지.
- 아이템 6개를 3개씩 2줄(윗줄 3개, 아랫줄 3개)로 배치. 아이템끼리 서로 멀리 떨어뜨리고 가장자리에도 넉넉한 여백.
- 6개 모두 비슷한 크기의 작은 아이템. 바닥에서 작게 보여도 무엇인지 알아볼 수 있게 외곽선과 실루엣을 뚜렷하게.
- 6개의 실루엣(모양)이 서로 확실히 달라야 함. 색만 다르고 모양이 비슷하면 안 됨.
- 각 아이템 아래에 아주 작은 그림자만. 글자, 번호, 라벨, 워터마크를 이미지 안에 절대 넣지 마.

[윗줄 — 오래된 집에서 찾은 물건: 낡고 먼지 앉은 생활용품 느낌]
1. 작은 여자아이용 흰 고무신 한 짝 (한 짝만). 코가 살짝 올라간 전통 고무신 모양, 때가 타 있음.
2. 작은 아이용 사기 밥그릇. 가장자리 한 군데가 이가 빠져 있고, 옅은 파란 무늬.
3. 찢어진 흑백 가족사진 한 조각. 사진 속 사람 중 한 명만 유독 하얗게 바래서 잘 안 보임. 모서리가 구겨지고 찢긴 자국.

[아랫줄 — 호수 바닥에서 건진 물건: 젖어 있고 물때와 진흙이 묻은 느낌]
4. 둥근 손거울. 테두리는 낡은 금속, 거울 면은 물기로 뿌옇고 진흙이 조금 묻음.
5. 녹슨 꽃 모양 머리핀(또는 브로치). 녹과 물때가 낀 오래된 장신구.
6. 물에 젖어 잉크가 번진 편지 봉투. 가장자리가 쭈글쭈글하고 얼룩져 있음.
```

## 결과물이 마음에 안 들 때 덧붙일 말

- 잘렸을 때: `오브젝트가 이미지 가장자리에 닿지 않게, 전체를 더 작게 그리고 여백을 두 배로 늘려줘.`
- 배경이 깨끗하지 않을 때: `배경을 무늬 없는 #FF00FF 단색으로만 다시 그려줘. 바닥이나 그림자를 배경 전체에 깔지 마.`
- 글자가 들어갔을 때: `이미지 안의 모든 글자와 숫자를 지우고 다시 그려줘.`
- 화풍이 다를 때: `첨부한 이미지와 같은 픽셀 크기와 색감의 픽셀아트로 다시 그려줘. 매끈한 일러스트 말고 픽셀아트.`
