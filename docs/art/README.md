# docs/art/ — 아트워크 관리

ProjectS의 아트 리소스를 **리스트 → 발주 → 수령 → 적용** 순서로 관리하는 폴더.
게임에 들어가는 모든 그림은 사람이 직접 제작/제공한 원본 시트에서 잘라 쓴다
(외부 에셋 팩 사용 안 함, v0.34~).

| 파일 | 역할 |
|---|---|
| [RESOURCE_LIST.md](RESOURCE_LIST.md) | ID 규칙(분류 접두 + 대역)과 리소스 전체 목록·상태 |
| [orders/](orders/) | 발주서. 한 번 발주할 묶음마다 `ORDER-NNN.md` 하나 + 이미지 생성 AI용 복붙 프롬프트 `ORDER-NNN_gemini.md` |
| [`assets/README.md`](../../assets/README.md) | 받은 원본 시트 → 잘라낸 파생물 대응표 (적용 기록) |

## 워크플로

1. **리스트 기록** — 새로 필요한 그림이 생기면 `RESOURCE_LIST.md`의 ID 규칙(`CH`/`MP`/`OB`/`UI` + 대역)에 따라 ID를
   붙여 추가. 근거(어느 씬/기획 항목에서 필요한지)를 같이 적는다.
2. **발주** — 같이 그리면 좋은 항목들을 묶어 `orders/ORDER-NNN.md` 작성
   (`orders/_TEMPLATE.md` 복사). 리스트의 상태를 `발주됨(ORDER-NNN)`으로 바꾼다.
3. **수령** — 사람이 그린 시트를 `assets/` 루트에 다음 번호로 올린다
   (`asset005.png`, `npc004.jpg` …). 원본은 지우지 않고 보관.
4. **적용** — 시트에서 잘라 `assets/` 하위 폴더에 저장 → 씬에 연결 →
   `assets/README.md` 대응표 갱신 → `RESOURCE_LIST.md` 상태를 `적용됨`으로 →
   `tests/run_all.sh` + `qa/run_all.sh` 통과 및 스크린샷 육안 확인.

## 공통 제작 규격 (발주서에 항상 첨부)

- **화면**: 1280×720 뷰포트, 탑다운 2D(약간 비스듬한 시점), 1980~90년대 한국 시골 여름.
- **타일 그리드**: 32×32 px. 바닥 타일은 이음새 없이 반복 가능해야 함.
- **캐릭터**: 게임 내 높이 약 70 px(폭 약 30 px). 원본은 더 크게 그려도 됨 — 축소해서 씀.
  방향은 정면/좌/우/뒤 4방향, 걷기는 방향당 3프레임(`pc001.jpg`와 같은 3열×4행 배치).
- **소품**: 32~64 px 정도(1~2타일). 나무/덤불 같은 큰 오브젝트는 150~215 px 높이.
- **배경**: 가능하면 **투명 PNG**. 어렵다면 단색 배경 + 오브젝트 간 여백 충분히
  (체크무늬·격자·설명 글자가 그림에 닿으면 잘라낼 때 같이 딸려 옴 — v0.37 낙서 재크롭 사례).
- **시트 구성**: 한 장에 여러 개를 그릴 땐 칸 사이 여백을 넉넉히, 칸 안에 라벨 글자 넣지 않기.
- **잘림 금지**: 오브젝트 전체가 칸 안에 들어와야 함(v0.37 `hopscotch`/`bush_berry` 잘림 사례).
