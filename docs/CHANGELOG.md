# CHANGELOG.md — 버전별 변경 로그 (사람 확인용)

이 문서는 **사람이 나중에 훑어보기 위한 로그**다. 에이전트가 작업 중
참고하는 문서가 아니다(그 용도는 `docs/STATUS.md`). 이터레이션을 한 번
돌릴 때마다 버전을 0.01씩 올리고, 그 이터레이션에서 무엇을 바꿨는지
여기에 짧게 남긴다.

- 시작 버전: **v0.0** (2026-09-08, 이 로그를 시작한 시점의 상태 — 챕터 1
  "닫힌 일기장" 퍼즐 + 프롤로그 + 아이템 팝업/인벤토리 UI/목표 힌트 +
  콜리전/오클루전까지 구현된 상태).
- 버전 번호와 git 커밋은 1:1로 안 묶는다 — 버전은 "사람이 확인할 단위"
  기준이고, 커밋은 그보다 잘게 나뉠 수 있다.

## v0.08 (2026-09-08)

- v0.07에서 마당(현실)에만 넣었던 나무/덤불 조사를 꿈 씬에도 똑같이
  추가함. 같은 나무인데 꿈에서는 "그늘이 지지 않는다", "잎이 흔들리지
  않는다"처럼 미묘하게 이상하게 느껴지는 대사로 차이를 줌.

## v0.07 (2026-09-08)

- 마당의 나무 2그루와 열매 덤불을 조사할 수 있게 됨(Enter로 살펴보기).
  지금까지는 배경 장식이라 아무 반응이 없었는데, 짧은 분위기 대사가
  뜨도록 추가함. 새로운 사건이나 퍼즐은 아니고, "조사할 거리가 더
  필요하다"는 피드백에 대한 작은 대응.
