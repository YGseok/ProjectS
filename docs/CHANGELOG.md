# CHANGELOG.md — 버전별 변경 로그 (사람 확인용)

이 문서는 **사람이 나중에 훑어보기 위한 로그**다. 에이전트가 작업 중
참고하는 문서가 아니다(그 용도는 `docs/STATUS.md`). 이터레이션을 한 번
돌릴 때마다 버전을 0.01씩 올리고, 그 이터레이션에서 무엇을 바꿨는지
여기에 짧게 남긴다.

- 시작 버전: **v0.0** (2026-09-08, 이 로그를 시작한 시점의 상태 — 챕터 1
  "닫힌 일기장" 퍼즐 + 프롤로그 + 아이템 팝업/인벤토리 UI/목표 힌트 +
  콜리전/오클루전까지 구현된 상태).
- 버전 번호와 git 커밋은 1:1로 안 묶는다 — 버전은 "사람이 확인할 단위"
  기준이고, 커밋은 그보다 잘게 나뉠 수 있다.
- **날짜/시간 표기(2026-09-09부터)**: 항목 제목에 날짜뿐 아니라 시각까지
  `YYYY-MM-DD HH:MM` 형식으로 남긴다(예: `## v0.12 (2026-09-09 14:30)`).
  그 이전 항목(v0.11까지)은 날짜만 있음 — 소급 수정하지 않음.

## v0.16 (2026-09-09 17:17)

- 챕터 1 퍼즐 방식이 실제로 바뀜: 이제 마루 밑 판자·공기돌·사방치기·
  장독이 전부 현실이 아니라 **꿈 안**에 있고, 낮잠 한 번으로 들어간
  꿈 안에서 열쇠와 나무패를 자유 순서로 다 모아야 일기를 열 수 있다.
  일기를 열면 그게 곧 탈출(챕터 종료) — 예전처럼 꿈과 현실을 여러 번
  오갈 필요가 없다. 꿈 안에는 더 이상 "그냥 깨어나기" 버튼도 없다 —
  일기를 여는 것만이 유일한 탈출법.
