# CHANGELOG.md — 버전별 변경 로그 (사람 확인용)

이 문서는 **사람이 나중에 훑어보기 위한 로그**다. 에이전트가 작업 중
참고하는 문서가 아니다(그 용도는 `docs/STATUS.md`). 이터레이션을 한 번
돌릴 때마다 버전을 0.01씩 올리고, 그 이터레이션에서 무엇을 바꿨는지
여기에 짧게 남긴다.

- 시작 버전: **v0.0** (2026-09-08, 이 로그를 시작한 시점의 상태 — 챕터 1
  "닫힌 일기장" 퍼즐 + 프롤로그 + 아이템 팝업/인벤토리 UI/목표 힌트 +
  콜리전/오클루전까지 구현된 상태).
- 버전 번호와 git 커밋은 1:1로 안 묶는다 — 버전은 "사람이 확인할 단위"
  기준이고, 커밋은 그보다 잘게 나뉠 수 있다.

## v0.01 (2026-09-08)

로그를 시작한 시점의 스냅샷. 이 시점까지 누적된 내용은 `docs/STATUS.md`
