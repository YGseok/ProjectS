# docs/scenario/ — 외부 시놉시스 인박스

사람이 GPT 등 외부에서 정리 중인 시놉시스를 이 폴더에 `.md`로 올려둔다.
파일명은 업로드한 날짜 (예: `2026-09-02.md`). 과거 파일은 지우지 않고
그대로 쌓아 둔다 — 최신 파일이 최근 시놉시스지만, 이전 파일도 아이디어
소스로 유효하다.

## 이 폴더를 어떻게 쓰는가

- 스토리라인 작업(챕터 내용, 대사, 이벤트 설계 등) 시작 전에 이 폴더의
  최신 파일(들)을 참고한다.
- 시놉시스에 등장하는 소재/사물은 게임의 주요 흐름에 자연스럽게 녹여
  넣는다.
- 그중 일부는 **떡밥용 오브젝트**(퍼즐 키, 문을 여는 열쇠, 상호작용
  가능한 맥거핀 등)로 구체화한다. **시놉시스의 모든 아이템을 다 써야
  하는 것은 아니다** — 게임플레이/페이싱에 맞는 것만 고른다.
- 이 폴더 내용과 `docs/DESIGN.md`(특히 §2 진상)가 충돌하면, 더 최신
  날짜의 시놉시스 파일을 우선하되 판단이 애매하면 사람에게 확인한다.
