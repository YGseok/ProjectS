# assets/sprites/characters/player_placeholder/

**2026-09-17 갱신**: 사람이 확정 캐릭터 디자인 컨셉아트(`concept_pc001.webp`,
DESIGN.md 목표대로 흰 원피스를 입은 검은 머리 아이)를 제공해서, 정면(아래)
방향은 이제 그 그림을 다듬어 쓴다 — 더 이상 순수 placeholder가 아니다.
가공 과정(배경 제거, 게임 크기로 축소)과 원본은
[../concept_art/README.md](../concept_art/README.md) 참고.

**아직 남은 것**: 왼쪽/오른쪽/위(뒤) 방향의 실제 그림은 아직 없다 —
정면 그림을 그대로 재사용 중이라(왼쪽=정면, 오른쪽=정면을 `flip_h`)
지금은 어느 방향으로 움직여도 캐릭터가 계속 정면을 보는 것처럼 보인다.
다른 방향 그림이 생기면 `player_side.png`/`player_up.png`만 교체하면
된다(코드 변경 불필요 — `player.gd`가 파일명을 고정 참조).

| 파일 | 크기(px) | 용도 |
|---|---|---|
| `player_down.png` | 33×70 | 아래(정면)를 볼 때 — 확정 디자인 컨셉아트를 가공한 실제 그림 |
| `player_side.png` | 33×70 | 왼쪽을 볼 때 — **임시로 정면 그림을 그대로 재사용 중**(진짜 옆모습 아님). 오른쪽은 이 텍스처를 `flip_h`로 좌우 반전해서 재사용 |
| `player_up.png` | 33×70 | 위(뒤)를 볼 때 — **임시로 정면 그림을 그대로 재사용 중**(진짜 뒷모습 아님) |
