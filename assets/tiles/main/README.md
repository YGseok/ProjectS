`assets/downloads/`로 받아둔 것을 2026-09-04에 정리해 옮김. RPG Maker
MV/MZ 스타일 타일 시트 (호러 장르 실내/실외 세트 — `Inside_C.png`에 피 묻은

(엘프 소녀 데모 팩, 파이프라인 검증용 임시)와 달리 **이건 실사용 후보
에셋**이다.
